# インストール

| プラットフォーム | ファイル／方法 | モード |
|---|---|---|
| 🪟 Windows | `Stellio-Setup-<version>.exe` | デスクトップアプリ |
| 🪟 Windows ポータブル | `Stellio-v<version>-portable-win64.zip` | デスクトップアプリ（インストール不要） |
| 🍎 macOS | `.dmg`（Apple Silicon `arm64` または Intel `x86_64`） | デスクトップアプリ |
| 🐧 Linux | `Stellio-v<version>-x86_64.AppImage` | デスクトップアプリ |
| 🍓 Raspberry Pi / Linux | `install-pi.sh` | サーバー（ブラウザ） |
| 🖥️ Proxmox VE | `stellio-lxc.sh` | コマンド 1 つで LXC コンテナ |
| 📲 Android | コンパニオン APK | [リモート／モバイルアクセス](ja-Remote-Access) を参照 |

すべてのファイルは [Releases](https://github.com/stellio-app/stellio/releases) ページにあり、それぞれ `.sha256` チェックサムが付いています。

## Windows

1. Releases からインストーラーをダウンロードします。
2. `Stellio-Setup-<version>.exe` を実行します。
3. 完了です。

**ポータブル版**：好きな場所（ディスク、USB メモリ）に展開して `Stellio.exe` を実行します。データは実行ファイルの隣の `data` フォルダーに保存されます（`portable.flag` ファイルは残してください）。

> ⚠️ インストーラーは**コード署名されていません**。Windows SmartScreen が警告を表示することがあります。必要に応じて `.sha256` を確認してください。内蔵アップデーターはインストール前に検証します。

## macOS

`.dmg` を開き、Stellio を「アプリケーション」にドラッグします。お使いの Mac に合うファイルを選んでください：`arm64`（M1、M2、M3…）または `x86_64`（Intel）。ビルドは公証されていません。初回起動時は右クリック → **開く**。

> 画面が白いままの場合：ポート 5000 が macOS の「AirPlay レシーバー」に使われている可能性があります。その場合、Stellio は自動的に別の空きポートを選びます。[トラブルシューティング](ja-Troubleshooting) を参照してください。

## Linux（AppImage）

```bash
chmod +x Stellio-v*-x86_64.AppImage
./Stellio-v*-x86_64.AppImage
```
AppImage にはアップデート情報（`.zsync`）が含まれています。

## Raspberry Pi / Linux サーバー

**ヘッドレスサーバー**モード：Stellio はバックグラウンドで動作し、ブラウザから使います。詳細は [サーバー版](ja-Server-Edition) を参照してください。

```bash
curl -O https://raw.githubusercontent.com/stellio-app/stellio/main/install-pi.sh
chmod +x install-pi.sh
./install-pi.sh
```

## Proxmox VE

**Proxmox ホストのシェル**で：
```bash
bash -c "$(curl -fsSL https://raw.githubusercontent.com/stellio-app/stellio/main/stellio-lxc.sh)"
```
詳細は [サーバー版](ja-Server-Edition) を参照してください。

## アップデート

- **デスクトップ**：Stellio は GitHub で新しいバージョンを検出し、`.zip` パッチを適用します（Windows、macOS、Linux で同じ仕組み）。ダッシュボードの「アップデート」ウィジェットからアップデート画面を開けます。
- **サーバー**：同じ自動アップデート、または `update-stellio`（LXC コンテナ）／`./install-pi.sh`（Raspberry Pi）。
- 各バージョンの初回起動時に、不足しているモジュール（PDF 見積、表計算のインポート、通知など）が自動でダウンロードされます。

# はじめに
{{img:library}}


## 1. 初回起動
Stellio は**ガイドツアー**と「はじめに」チェックリストを表示します。ツアーは設定からいつでもやり直せます。

## 2. アカウントを作成する
アカウントは**ローカル**です：パスワード + 復旧コード + 秘密の質問。パスワードのリセットは 100% ローカルで、メールもインターネットも不要です。

## 3. ソースを追加する
**ソース**は、モデルが入っているフォルダーまたは共有です：
- ローカルフォルダー、単一ファイル、**SMB** または **NFS** 共有；
- コンピューターで検出された 3D フォルダーは**候補として提案**され、ワンクリックで追加できます；
- ソースごとに、表示するファイルの種類を選べます。

その後 Stellio がファイルをスキャンし、バックグラウンドで 3D サムネイルを生成します。

## 4. プリンターを追加する（任意）
**プリンター**ページを開きます：ネットワーク検出が見つかった機器を提案します。[プリンター](ja-Printers) を参照してください。

## 5. スライサーを選ぶ
Stellio はインストール済みのスライサー（OrcaSlicer、Bambu Studio、PrusaSlicer、Cura など）を自動検出します。送信ボタンでファイルをスライサーで直接開けます。

## ダッシュボード
ホームには、進行中の印刷、在庫不足、最近の印刷、最近のファイルがまとまっています。**ウィジェット**（約 20 種類）はドラッグ＆ドロップで並べ替え、非表示にできます：現在の印刷、在庫不足、最新の S.O.S Print、提案、Stellio インスタンス、完了したプロジェクト、ギャラリー、見積など。

## 毎日使うツール
- **コマンドパレット** `Ctrl+K`：移動、操作の実行、ファイル・タグ・スプール・プロファイルの検索。
- **通知センター**（ベル）：印刷完了、失敗、メンテナンス、在庫不足、スプールの乾燥。
- **フローティングウィジェット**：現在の印刷の進捗を表示し、すべてのページで見えます。
- **キーボードショートカット**：[設定とデータ](ja-Settings-and-Data) を参照。

# ステップバイステップガイド

Stellio のすべての機能について、**何のためにあり、どう使うか**を説明します。技術的な詳細は他のページにあります。ここでは実際に操作します。

> 💡 アプリのどこでも：`Ctrl+K` で**コマンドパレット**（移動、操作の実行、ファイル・タグ・スプールの検索）、`?` でショートカット一覧が開きます。

## Stellio の画面を知る

| メニュー | 用途 |
|---|---|
| **ダッシュボード** | 進行中の印刷、在庫不足、最近のファイル。ウィジェットは並べ替え可能。 |
| **ライブラリ** | すべての 3D モデル。サムネイル、タグ、フィルター、検索つき。 |
| **お気に入り** | お気に入りのモデルにワンクリックで。 |
| **もうすぐ印刷** | 印刷待ちリスト（並べ替え可能）。 |
| **プロジェクト** | 1 つの造形物に複数のファイルをまとめる。 |
| **プリンター** | ライブ監視、送信、メンテナンス、消耗部品。 |
| **フィラメント在庫** | スプール、残量切れの予測、乾燥。 |
| **履歴** | 送信したすべての印刷。成功・失敗の評価つき。 |
| **ギャラリー** | 印刷物の写真。 |
| **統計** | 信頼性、消費量、形式、レポート。 |
| **管理** | コスト、顧客向け見積もり、注文、会計。 |
| **工房モード** | タブレットやスマートフォン向けの全画面表示。 |
| **S.O.S Print** | 印刷失敗のガイド付き診断。 |
| **ダウンロード** | Printables、MakerWorld、Thingiverse などからモデルを取得。 |
| **修復** | 壊れたメッシュを見つけて修復。 |
| **コンバーター** | ある 3D 形式から別の形式へ変換。 |
| **重複** | 重複ファイルを見つける。 |
| **ごみ箱** | 削除したものを復元。 |
| **設定** | 外観、スライサー、AI、バックアップ、リモートアクセス。 |

## ファイルを追加して見つける

1. **ソースを追加**をクリック（または `Ctrl+K` から「ソースを追加」）し、**フォルダー**、単体のファイル、または **SMB / NFS** 共有を選びます。パソコン内で見つかった 3D フォルダーが候補として表示されます。
2. Stellio はバックグラウンドでスキャンして **3D サムネイル**を作成します。アプリを使っている間、生成は一時停止します。
3. モデルを探すには、**検索**バーに入力するか、AI 検索で自然な文章（「ヘッドホンスタンド」）で説明します。
4. エクスプローラーから 3D ファイルをドラッグ＆ドロップすると、そのまま追加できます。

💡 アーカイブ（ZIP、RAR、7z、TAR）は展開せずに中身を見られます。

## タグ・お気に入り・フィルターで整理する

1. ファイルの **⋯** メニューを開くか、複数選択（`Shift+クリック` で範囲選択）して一括操作します。
2. 色付きの**タグ**を手動で追加するか、AI の提案に任せます。`T` でタグ管理を開きます。
3. 星をクリックしてモデルを**お気に入り**に（`F` でお気に入りを開く）。
4. **フィルター**（種類、サイズ、重量、印刷状況、「フィラメント在庫」）を組み合わせ、**保存**して再利用します。
5. 多数のファイルを改名するには、**一括リネーム**（検索/置換、接頭辞、接尾辞、連番）を使います。確定前にプレビューできます。

## 3D でモデルを確認・準備する

1. ファイルのサムネイルをクリックすると **3D ビューアー**が開きます（オフラインでも動作）。
2. 回転とズームができ、複数プレートの 3MF ではプレートを切り替えられます。
3. **造形可否の分析**（オーバーハング）を実行すると、Stellio が推奨の**向き**を提案します。
4. **自動配置**で、プリンターのベッド上に複数のパーツを並べます。
5. ビューアーから結果をスライサーに送信します。

## 壊れたメッシュを修復する

1. **修復**を開くと、穴や開いた辺のあるファイルが一覧表示されます（サムネイル作成時にバックグラウンドでも分析されます）。
2. ファイルを選んで**修復**を実行し、**修復前 / 修復後**を比較します。
3. ファイルはその場で修復され、念のため `.bak` の安全コピーが残ります。

## ファイルを変換する

1. **コンバーター**を開き、1 つ以上のファイル（STL、3MF、OBJ、PLY、AMF、STEP）を選びます。
2. 出力形式を選びます：STL、3MF、OBJ、PLY、OFF、GLB。
3. 必要に応じて**メッシュを自動修復**と**元のファイルを削除**にチェックを入れます。
4. 開始します。一括変換はいつでもキャンセルでき、変換済みのファイルは残ります。

## 整理整頓：重複とごみ箱

1. **重複**を開くと、同一のファイルと**形状が近い**ファイル（同じモデルの改名・再エクスポート）がグループ化されます。
2. 残したいものを選び、他は削除します。
3. 誤って削除した？ `Ctrl+Z` で 5 分間は取り消せます。**ごみ箱**はそれより長く保管し、復元や完全削除ができます。

## ファイルをプロジェクトにまとめる

1. **プロジェクト**を開いて作成し、同じ造形物のファイル（本体、ふた、サポートなど）を追加します。
2. プロジェクトに追加した**複数プレート**の 3MF は、プレートごとの 3MF に分割されます（⋯ メニューの**プレートを分割**でも可能）。
3. 進捗（「進行中」/「完了」）を確認し、**プロジェクトコスト**をクリックすると全体の原価を計算できます。

## モデルをダウンロードする

1. **ダウンロード**を開き（または `Ctrl+N`）、モデルのリンク（Printables、MakerWorld、Thingiverse、Nexprint、Creality Cloud、Snapmaker Space）を貼り付けます。
2. 求められたアカウントを一度だけ接続します（[ダウンロード](ja-Downloads)を参照）。
3. 保存先の**ソース**を選びます。ファイルは**出典**（リンク、作者、ライセンス）つきで保存されます。
4. Stellio は毎日、モデルの**新バージョン**がないか確認します。**いいね一覧**と**自分の作品**で、接続済みアカウント上のモデルを見つけられます。

## プリンターを接続する

1. **プリンター → 追加**を開くと、**ネットワーク検出**が見つけた機器を提案します。見つからない場合は、種類、アドレス、アクセスキーを入力します。
2. **造形サイズ**（X、Y、Z）を入力します。大きすぎるパーツは送信前に Stellio が警告します。
3. 必要なら**このプリンターのスライサー**（1.0.8）を選びます。この機械ではそのスライサーが開きます。
4. 便利なオプションを有効にします：**タイムラプス**、**造形終了時の写真**、**AI 監視**、**スマートプラグ**（実際の消費電力）。

## ファイルをスライサーに送る

1. ライブラリまたはビューアーで**スライサーに送信**をクリックします。
2. ウィンドウで**見積もり**（重量、時間）を確認し、**プリンター**、**スプール**、**設定プロファイル**を選ぶか、「自動」のままにします。
3. **印刷前チェック**を読みます：乾燥が必要なスプール、研磨性フィラメント、サイズ超過、材料不足。
4. **送信**をクリックすると、そのプリンターのスライサー（または設定のスライサー）でファイルが開き、機械に紐づけたプロファイルが読み込まれます。指定した場合、スプールの使用量が差し引かれます。

💡 プロファイルをプリンターに紐づけるには、設定 → スライサーからインポートします。

## 次の印刷に備える：「もうすぐ印刷」

1. ファイルの **⋯** メニューで**もうすぐ印刷に追加**を選びます。
2. **もうすぐ印刷**を開き、ドラッグして**並べ替え**ます。
3. 項目をそのままスライサーに送るか、リストから外します。

## 印刷を見守る

1. プリンターのカードに、温度、進捗、**ライブカメラ**、現在のファイル名が表示されます。
2. **フローティングウィジェット**がすべてのページで進捗を表示します。
3. **ベル**が通知します（完了、失敗、メンテナンス、在庫不足）。**プッシュ通知**（ntfy、Telegram、Discord、webhook）を有効にすると、ウィンドウを閉じていても届きます。
4. 100% になると、Stellio が**終了時の写真**を撮ります。ワンクリックで*成功*か*失敗*かを記録できます。**タイムラプス**は自動で作成されます。

## 評価・再印刷・写真の確認

1. **履歴**を開き、プラットフォーム、結果、日付で絞り込みます。
2. 各印刷を**成功**または**失敗**で評価します。推奨や統計に反映されます。
3. **ファイルを見る**、または前回と同じ設定で**再印刷**します。
4. 写真は**ギャラリー**で見られます。**自分の G-code** には、ファイルに紐づく G-code が保存され、**スライサーで開く**ボタンがあります。

## スプールを管理する

1. **フィラメント在庫**を開き、スプールを手動で追加（または Excel/CSV をインポート）し、**Spoolman**、**TigerTag**、**OpenPrintTag** を連携するか、**Open Filament Database** でスプールを検索します。
2. スライサーへ送信するときにスプールを選ぶと、Stellio が消費量を**差し引き**、残量が足りるか確認します。
3. **計量と予測**でスプールを量ると、Stellio が**残量切れの日**を見積もり、近づくと知らせます。
4. スプールの**乾燥**を記録して状態を追跡し、**買い足す**でメーカーのショップを開きます。

## コストを計算して見積書を作る

1. ファイル（**コスト**）またはプロジェクト（**プロジェクトコスト**）から計算機を開きます。
2. 材料、電気、**機械の消耗**、**固定費**、**利益率**、**数量**を確認すると、単価と合計が表示されます。
3. **見積書を生成（PDF）**をクリックし、顧客と品名を入力します。PDF は保存され、**見積書**ウィジェットから確認できます。
4. 既定の利益率は**設定 → 印刷の価格設定**で決めます。

## 注文・顧客・請求書を管理する

1. 設定で「コスト・見積もり・請求機能を有効にする」をオンにすると、**管理**画面が表示されます。
2. 見積書を**追跡リンク**つきで顧客に送ります。顧客はオンラインで承認または辞退でき、承認すると印刷タスクが作られます。**Stellio は支払いを一切処理しません。**
3. **注文キュー**、支払い、前受金の請求書、クレジットノートを確認します。**スマート割り当て**は適したプリンターを提案しますが、印刷を勝手に開始することはありません。
4. 毎月、**会計**データ（CSV と PDF を含む ZIP）をエクスポートします。

## プリンターのメンテナンス

1. プリンターのカードで**メンテナンス**を開き、**ブランド**を選ぶと、推奨タスクが表示されます。
2. 追跡に追加すると、印刷時間と経過日数に応じて「要対応」になります。
3. **消耗部品**（ノズル、プレート、ベルト）をアラートの閾値つきで、また**キャリブレーション**をフィラメントごとに記録します。

## 失敗を診断する：S.O.S Print と AI

1. **S.O.S Print** を開き、問題を説明します（写真も添付可能）。
2. 質問に 1 つずつ答えます（最大 4 つ）。Stellio が原因の候補を絞り込み、**最終診断**を出します。
3. ローカル AI を使うには、[Ollama](https://ollama.com/) をインストールし、**設定 → 人工知能**で設定します。**失敗の監視**は警告しますが、印刷を止めることは決してありません。

## スマートフォンやリモートで Stellio を使う

1. **設定 → モバイルアクセス**で **QR コード**を読み取ると、ライブラリがスマートフォンで開きます（アプリのようにインストール可能）。
2. **Android** アプリは、専用の QR コードを読み取ります。
3. 外出先では、**リモートアクセス**（Cloudflare Tunnel またはカスタムアドレス）を有効にするか、一時的な**共有リンク**を作成します。
4. **ゲストアカウント**で閲覧専用の共有ができます。

## バックアップと復元

1. **設定 → バックアップとデータ**を開き、データを**エクスポート**します（.zip）。
2. **自動バックアップ**をスケジュールします。
3. 復元するには、.zip ファイルを**インポート**します。Stellio のアップデートがデータに触れることはありません。

## 印刷コストの計算
材料、電気代、機械の摩耗（時間あたり）、固定費、利益率（%）、数量：単価と合計を 1 円単位まで正確に計算します。
- **既定の利益率**は *設定 → 印刷の価格設定* で一度設定します。履歴ではコストの隣に**販売価格**が表示され、統計は実コストを使い続けます。
- **プロジェクトコスト**：プロジェクト内のすべてのファイルに同じ計算を適用。
- **スマートプラグ**：実測電力が電気代の見積に置き換わります。
- 印刷の **CO₂ フットプリント**（材料 + 電力）。

## PDF 見積
計算ツールから生成：顧客、品名、メモ；設定可能なヘッダー（氏名/会社名、ロゴ、住所、電話、メール、ウェブサイト、税番号）とフッターの法的表示。見積はすべて保存され（PDF コピー）、**見積**ウィジェットで閲覧できます。

## 「管理」画面
*コスト、見積、請求機能を有効にする* にチェックを入れると表示されます：

# サーバー版

**サーバー版**は、Linux（Raspberry Pi、VM、LXC、Docker）上、または `STELLIO_HEADLESS=1` を指定したときに有効になります。Windows と macOS はデスクトップアプリのままです。Stellio はバックグラウンドで動作し、ブラウザから使います：`http://<ip>:5000`。

## Raspberry Pi / Linux
要件：Raspberry Pi 4 または 5 を推奨、**64 ビット**の Raspberry Pi OS。

`install-pi.sh` は、システム依存パッケージ（`ffmpeg`、`unrar`、3D レンダリングライブラリ）、専用の Python 環境、起動時に開始してクラッシュ時に再起動する `stellio` **systemd サービス**をインストールします。

```bash
sudo systemctl status stellio
sudo systemctl restart stellio
sudo journalctl -u stellio -f
```
メモリが少ない場合は、Python 依存パッケージのインストールが失敗するときにスワップを増やし、スクリプトを再実行してください。

## Proxmox VE（LXC コンテナ）
`stellio-lxc.sh` スクリプトは**既定**または**詳細**設定（CTID、コア数、RAM、ディスク、ブリッジ、VLAN、DHCP または固定 IP、ストレージ、マウントするホストフォルダー）を提示し、続いて：
- **非特権 Debian 12** コンテナを作成します（2 コア、RAM 2 GB、ディスク 32 GB、起動時に自動開始）；
- `install-pi.sh` で Stellio をインストールします；
- アドレス `http://<コンテナのIP>:5000` と root パスワードを表示します。

```bash
pct exec <CTID> -- update-stellio              # 更新
pct exec <CTID> -- journalctl -u stellio -f    # ログ
```
- **非対話モード**：変数 `var_mode=default var_cpu=4 var_ram=4096 var_disk=16 var_ip=192.168.1.50/24 var_gw=192.168.1.1`（一覧はスクリプトの先頭）。
- **ストレージ**：`var_choose_storage=1`、`var_storage`、`var_template_storage`。
- スクリプトの**言語**：`var_lang=ja`（fr、en、de、es、pt、it、zh、ja）。
- **ソース**：このコンテナでは **SMB/NFS** 共有のみが提示されます。`var_mount=/host:/mnt/models` を指定すると「ローカルフォルダー」も許可されます。設定：`/etc/systemd/system/stellio.service.d/sources.conf`（`STELLIO_ALLOWED_SOURCE_TYPES`）。

## 保護機能（1.0.7）
`install-pi.sh` は次を設定します：
- **毎分のチェック**（`stellio-watchdog`）：Stellio が応答しなくなったら再起動（チェック 3 回連続失敗、起動後 3 分の猶予）、停止していれば起動、IP アドレスを失ったらネットワークを再起動、ディスクの空きが 300 MB 未満ならログと apt キャッシュを削除；
- 再起動を**決して諦めない**サービス；
- **CPU 75%**、**RAM 75%（減速）/ 85%（ハードリミット）**の上限、低優先度、メモリ不足時は Stellio を最初に犠牲にする；
- ログを **100 MB** に制限。

チェックの介入記録：`journalctl -t stellio-watchdog`。既存のコンテナは `update-stellio` ですべてを受け取れます。

## サーバー版の特徴
- ☁️ 任意の**オンライン AI**（[人工知能](ja-AI) を参照）。
- 📥 **スライサープロファイル**：Stellio は PC 上のスライサーを見ることができず、スライサーのクラウド（Orca Cloud、Bambu Cloud など）にも接続しません。プロファイルをエクスポートし（OrcaSlicer：ファイル → エクスポート → プリセットバンドルをエクスポート）、*設定 → マイスライサープロファイル* でインポートするか、**監視対象のプロファイルフォルダー**（Syncthing、ネットワーク共有、scp など）を使ってください。
- 🐯 **TigerTag**：メールとパスワードによる公式サインイン。Google アカウントの場合は、まず TigerTag アプリの「パスワードを忘れた場合」でパスワードを設定してください。代替手段：TigerTag Studio のデータフォルダーをサーバーにコピー。
- アップデート後、ブラウザは自動的に再読み込みされます。

# トラブルシューティング

まずは**診断**（設定 → 診断）をエクスポートし、報告用に保管してください。

## 起動時に画面が白いまま（macOS）
ポート **5000** は *AirPlay レシーバー* に使われていることがよくあります（Safari で 403）。Stellio は現在、空きポート（5001–5030）を**自動的に**選びます。それでも解決しない場合：システム設定 → 一般 → AirDrop とHandoff → *AirPlay レシーバー* をオフにします。ログ：`~/.stellio/stellio.log`（通常のレベルでは空です：デバッグモードを有効にしてください）。

## LXC コンテナに接続できなくなった
Proxmox のシェルから：
1. `pct status <CTID>`。停止していれば `pct start <CTID>`。
2. `pvesm status`：**ストレージが満杯**？ ストレージを共有している場合に最も多い原因です。
3. `pct exec <CTID> -- free -m` と `dmesg -T | grep -i "oom\|killed process"`：メモリ不足。
4. `pct exec <CTID> -- ip -4 a`：DHCP の IP が変わっていませんか？ ルーターで予約してください。
5. `pct exec <CTID> -- systemctl status stellio` と `journalctl -u stellio -n 100`。

1.0.7 以降は、自動監視が一般的なケースに対処します。`journalctl -t stellio-watchdog` を参照してください。

## サムネイルが遅い、または表示されない
- *設定 → サムネイル性能* を選びます：小さなマシンでは**エコ**。
- 非常に重いファイルは、タイムアウト後に代替サムネイルのままになります。
- アプリを使っている間は生成が一時停止します。これは正常です。

## プリンターが検出されない
- 同じネットワークにあるか確認してください（VLAN、ゲスト Wi-Fi）。
- IP アドレスとキーを使って手動で追加してください。
- Bambu Lab：LAN モードを有効にします。Klipper：Moonraker API に到達できる必要があります。

## 印刷終了時の写真がない
プリンターで*印刷終了時の写真*のチェックボックスを有効にし（AI 監視やスマートプラグと同様）、カメラが応答しているか確認してください。

## 「モジュールが見つかりません」
各バージョンの初回起動時に、Stellio は不足しているモジュールをダウンロードします。インターネット接続を確認してください。必要がない限り `STELLIO_NO_AUTO_INSTALL` は設定しないでください。

## Windows SmartScreen / macOS がアプリをブロックする
インストーラーは署名されていません。`.sha256` を確認してから、*詳細情報 → 実行* (Windows)、または右クリック → *開く* (macOS) を選びます。
